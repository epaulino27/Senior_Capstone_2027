Starlight & Steel
(work in progress)

This code features the first demo version of my graphic adventure game. 

Gameplay Walkthrough
  https://youtu.be/LmlqMe7yTAo

Features
  save system
  npc interaction
  10 item interactions of 2 types (paper, rolly polly collection)
  portal teleportation in relation to puzzle mechanic
  inventory system
  music

Installation Instructions
  1. Download the attached MacOS game files
  2. Unzip it
  3. Run the .app file in the now unzipped folder
  4. Play!

Lore & Level Writeup
  These are located in this github repository under the titles of "D3 Lore.pdf" and "Level 1 Gameplay.pdf".
